# Spark β

アカペラのシャッフルバンドを自動で編成するツールです。
参加申し込みのアンケート CSV を入れると、バンド表の CSV が出てきます。

> **運営休止と OSS 化について**
> Spark β はもともと、参加登録からバンド編成、バンドごとのチャットまでを備えた Web サービス（spark-beta-v2.vercel.app）でした。2026年11月、開発者が他のプロジェクトに軸足を移し、利用者の個人情報を預かるサービスを安全に保守し続ける体制が取れなくなったため、運営を休止しました。
> サービスは畳みますが、中心にあった **バンド編成の仕組みだけを OSS として手渡します**。イベントの運営団体や関連企業の方は、自由に使い、自分たちのイベントに合わせて手を入れてください。

## 使われたイベント

### 九州・山口アカペラ3年生同期ライブ「Spark」（2025年5月・福岡）
開発者が副代表としてシャッフルバンド企画を提案し、運営を担当したライブで、Spark β の名前の由来です。企画には **40名** が応募してくれましたが、ライブ全体で54バンドが出演する中、出演枠の都合で **2バンド（12名）** しか出してあげられませんでした。
このとき、パートや大学、経験の釣り合いを見ながら、納得のいく組み合わせを人の手で作ろうとすると、とんでもなく時間がかかることを思い知りました。この組み合わせ作りを仕組みに任せたい、というのが Spark β の出発点です。

### 九州アカペラパーク（2025年9月・福岡 舞鶴公園）
Web サービスとして使われたイベントです。
- 登録ユーザー 41名（13大学）、イベント参加登録 21名（10大学）
- 6人組のシャッフルバンドを **2組** 自動編成し、バンドごとのチャットで練習の相談まで行いました
- 残る9名はバンドを組めませんでした。全パートがそろう6人組だけを作る方式だったため、パートの偏りがあると余りが出ます

### Re:Flare（2026年2月）
Web サービスから編成ロジックだけを取り出し、このリポジトリのコマンドライン版に作り直して使いました。
- 応募 **34名を全員、6バンド**（6人×4、5人×2）に編成。全バンドに必要なパートがそろう
- 5人組（Perc. なし）を許し、第二・第三希望のパートまで使うことで、余りを出さない形にしました

## 仕組み

1. 人数から、6人組と5人組を何組ずつ作るかを決める（6人組を優先し、余りが出ないように5人組で調整）
2. 応募者をランダムに並べてバンドに割り振り、各バンドで第一〜第三希望の中から、いちばん希望が叶うパートの割り当てを選ぶ。全パートがそろわない並びは捨てる
3. バンドごとに4つのスコアを出し、合計が最も高い並びを残す。これを何万回もくり返す
4. 必要なら、メンバーを入れ替えて改善できるところまで改善する（ローカルサーチ）

| スコア | 何を見るか |
|---|---|
| U | 大学がばらけているか |
| E | 経験年数がばらけているか |
| W_part | 希望パートがどれだけ叶っているか（第一希望ほど高い） |
| W_genre | 歌いたいジャンルがそろっているか |

詳しい式と制約は `docs/要件定義書.md`、モジュール構成は `docs/実装計画書.md` にあります。

## 使い方

必要なもの：Node.js 18 以上

```bash
npm install
npm run run -- input/applicants_sample.csv output/bands.csv
```

オプション：

| オプション | 説明 | 既定値 |
|---|---|---|
| `--trials=N` | ランダムに並べ替えて試す回数 | 50000 |
| `--seed=N` | 乱数シード（同じ入力で同じ結果を出したいとき） | なし |
| `--local-search` | 探索のあとにメンバー入れ替えで改善する（おすすめ） | なし |

```bash
node dist/main.js input/applicants.csv output/bands.csv --trials=20000 --local-search
```

### 入力 CSV

1行目がヘッダー、2行目以降が応募者です。`input/applicants_sample.csv` が見本です（架空のデータ）。

| 列 | 内容 |
|---|---|
| id | 応募者ID（重複しない値） |
| name | 名前 |
| university | 大学名 |
| experience_years | 経験年数（数値） |
| first_part / second_part / third_part | 第一〜第三希望パート（`Lead`, `1st`, `2nd`, `3rd`, `Bass`, `Perc.`） |
| can_arrange | アレンジできるか（「はい」／「いいえ」） |
| genre | 歌いたいジャンル |

### 出力 CSV

1バンド1行で、バンド番号・人数・各スコアと、メンバー（`名前(担当パート)` を「、」でつないだもの）が並びます。

## 注意

- 参加者の名前や大学は個人情報です。実際の回答 CSV をリポジトリに入れないでください（`.gitignore` で `input/` のサンプル以外を除外しています）
